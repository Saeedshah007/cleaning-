# چرخهٔ نظافت خانه — نسخهٔ وب‌اپ واقعی

این نسخه، برخلاف صفحهٔ آرتیفکت قبلی، یه اپلیکیشن واقعیه: لاگین جدا برای هرکدوم از ۴ نفر،
دیتابیس واقعی (نه حافظهٔ مرورگر)، و نوتیف پوش واقعی که حتی وقتی اپ بسته‌ست هم می‌رسه.
منطق چرخش وظایف، وزن‌دهی، جریمهٔ خودکار و قفل‌شدن بعد از جریمه — عیناً همون منطقِ
تست‌شدهٔ نسخهٔ قبلیه، فقط حالا روی سرور اجرا می‌شه.

## قبل از هرچی: یه واقعیت مهم دربارهٔ «رایگان»

هیچ ترکیب کاملاً رایگانی وجود نداره که هم صددرصد همیشه‌روشن باشه، هم پوش رو تضمینی برسونه.
با انتخابی که کردید (Render رایگان)، این محدودیت واقعیه و باید بدونیدش:

- سرویس رایگان Render بعد از ۱۵ دقیقه بی‌کاری می‌خوابه و بیدار شدنش حدود ۱ دقیقه طول می‌کشه.
- برای اینکه بیدار بمونه و منطق جریمه/یادآوری هم تیک بخوره، یه سرویس کرون رایگان بیرونی
  (cron-job.org) هر ۱۰ دقیقه بهش سر می‌زنه. این یعنی بین هر بار سر زدن، اگه دقیقاً همون لحظه
  کسی نوتیف بفرسته براش (مثلاً جریمهٔ آنی)، ممکنه چند دقیقه دیر برسه — نه آنیه، ولی قابل‌اعتماده.
- **دامنهٔ رایگان واقعی** (یه اسم دلخواه دات‌کام مجانی) عملاً وجود نداره. چیزی که رایگانه یه
  ساب‌دامین روی دامنهٔ خودِ هاسته، مثلاً `khoone-shoma.onrender.com` — با HTTPS خودکار، که برای
  نصب PWA و پوش کاملاً کافیه، فقط دامنهٔ اختصاصی خودتون (`something.com`) نیست.

اگه بعداً دیدید این محدودیت‌ها اذیت می‌کنه، ارزون‌ترین راه برای رفعش Fly.io هست (~$2/ماه، همیشه‌روشن).

## معماری

- **بک‌اند:** Node.js + Express
- **دیتابیس:** SQLite سازگار با libSQL — محلی یه فایل، در پروداکشن [Turso](https://turso.tech) (رایگان)
- **ورود:** هر نفر با اسم + پین ۴ رقمی، نشست با کوکی امضاشده (JWT) — چون سرور رایگان
  گاهی ری‌استارت می‌شه، نشست‌ها state-less هستن و با ری‌استارت از دست نمی‌رن.
- **نوتیف:** Web Push استاندارد (VAPID) — سرویس‌ورکر واقعی، نه شبیه‌سازی.
- **کرون:** یه مسیر HTTP (`/api/cron/tick`) که سرویس رایگان بیرونی صداش می‌زنه.

## مرحلهٔ ۱ — نصب محلی (برای تست قبل از دیپلوی)

```bash
npm install
cp .env.example .env
```

فایل `.env` رو باز کن و این‌ها رو پر کن:
- `JWT_SECRET` — یه رشتهٔ تصادفی طولانی (مثلاً `openssl rand -hex 32` توی ترمینال)
- `APP_TIMEZONE` — منطقهٔ زمانی **واقعی خونه‌تون** (مثل `America/Toronto`). این خیلی مهمه —
  اگه خالی/UTC بمونه، ددلاین نیمه‌شب طبق ساعت غلط حساب می‌شه.
- `CRON_SECRET` — یه رمز دلخواه (فقط شما و cron-job.org می‌دونید)

بعد:
```bash
npm run seed        # برای هر ۴ نفر یه پین ۴ رقمی می‌سازه و توی ترمینال نشون می‌ده — یادداشت کن
npm start           # سرور روی http://localhost:3000 بالا میاد
```

با مرورگر برو `http://localhost:3000`، با یکی از اسم‌ها و پینی که seed داد وارد شو.

## مرحلهٔ ۲ — ساخت دیتابیس رایگان Turso

1. برو [turso.tech](https://turso.tech) و ثبت‌نام کن (بدون کارت اعتباری).
2. یه دیتابیس جدید بساز (از داشبورد یا CLI).
3. از تنظیمات دیتابیس، `Database URL` (چیزی شبیه `libsql://xxxx.turso.io`) و یه
   `Auth Token` بگیر.
4. این دو تا رو بعداً به‌عنوان `TURSO_DATABASE_URL` و `TURSO_AUTH_TOKEN` توی Render می‌ذاری.

## مرحلهٔ ۳ — ساخت کلیدهای نوتیف (VAPID)

```bash
npm run gen-vapid
```

دو خط `VAPID_PUBLIC_KEY` و `VAPID_PRIVATE_KEY` چاپ می‌شه — یه‌بار برای همیشه بسازشون و نگه‌شون دار.

## مرحلهٔ ۴ — دیپلوی روی Render (رایگان)

1. کد رو به یه ریپوی GitHub پوش کن (اگه گیت‌هاب نداری، یه‌بار ثبت‌نام رایگان کن).
2. توی [render.com](https://render.com) ثبت‌نام کن (رایگان، بدون کارت).
3. **New + → Web Service** → ریپوی گیت‌هابت رو وصل کن.
4. تنظیمات:
   - **Runtime:** Node
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
   - **Instance Type:** Free
5. توی بخش **Environment**، همهٔ متغیرهای فایل `.env` رو (به‌جز خطوط توضیحی) یکی‌یکی اضافه کن:
   `JWT_SECRET`, `APP_TIMEZONE`, `CRON_SECRET`, `REMINDER_HOUR`, `REMINDER_WINDOW_MINUTES`,
   `VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`, `VAPID_SUBJECT`, `TURSO_DATABASE_URL`,
   `TURSO_AUTH_TOKEN`, و `NODE_ENV=production`.
6. Deploy بزن. بعد از بالا اومدن، یه آدرس شبیه `https://اسم-اپت.onrender.com` می‌گیری.
7. یه‌بار seed رو روی همون دیتابیس Turso اجرا کن (از کامپیوتر خودت، با همون
   `TURSO_DATABASE_URL`/`TURSO_AUTH_TOKEN` توی `.env` محلی):
   ```bash
   npm run seed
   ```
   پین‌های چاپ‌شده رو به هر ۴ نفر بگو.

## مرحلهٔ ۵ — نگه‌داشتن اپ بیدار + تیک زدن جریمه/یادآوری (cron-job.org)

1. برو [cron-job.org](https://cron-job.org) و رایگان ثبت‌نام کن.
2. یه Cronjob جدید بساز:
   - **URL:** `https://اسم-اپت.onrender.com/api/cron/tick?secret=همون-CRON_SECRET`
   - **Schedule:** هر ۱۰ دقیقه
3. ذخیره کن. از این به بعد، همین پینگ هم اپ رو بیدار نگه می‌داره هم جریمه‌های خودکار و
   یادآوری عصرگاهی رو تیک می‌زنه.

## مرحلهٔ ۶ — نصب روی گوشی هرکدوم از ۴ نفر

1. آدرس Render رو توی گوشی باز کنن (Chrome/Safari).
2. وارد بشن (اسم + پین).
3. مرورگر گزینهٔ «Add to Home Screen» / «نصب اپ» رو نشون می‌ده — بزنن.
4. توی صفحهٔ «امروز»، روی «فعال‌سازی نوتیف» بزنن و اجازه بدن — از این به بعد حتی با اپ بسته
   هم نوتیف جریمه/یادآوری می‌رسه.

## نکات مهم

- **پین‌ها:** فقط زمان seed یا `npm run reset-pin -- <اسم> <پین‌جدید>` به‌صورت متن ساده دیده
  می‌شن؛ بعدش فقط هش‌شده توی دیتابیسه.
- **قفل‌شدن بعد از جریمه:** وضعیت هر کاری که ددلاینش گذشته و جریمه‌ش ثبت شده، دیگه قابل تغییر
  نیست — نه از سمت کاربر، نه با رفرش کردن.
- **جریمهٔ دستی:** توی تب «جریمه‌ها» هم می‌شه دستی جریمه ثبت/حذف کرد (برای مواردی که سیستم
  پوششش نمی‌ده).
- **تغییر منطقهٔ زمانی/ساعت یادآوری:** با تغییر `APP_TIMEZONE`/`REMINDER_HOUR` توی Render و
  ری‌دیپلوی.
- این پروژه برای ۴ نفر مشخص (سعید، خیبر، وحید، احسان) هاردکد شده — تغییر اسم‌ها یعنی ویرایش
  `src/rotation.js` و `public/app.js`.
